
# RenormHNet
RenormHNet (**renorm**alized **H**amiltonian neural **net**work) is the code accompanying the paper "Machine-Learning Spin-Fermion Models for Strongly Disordered Magnets: Sb-Doped MnTe". 

This code is built as a patch to [DeepH-pack](https://github.com/mzjb/DeepH-pack.git), 
and retains its original workflow. Installation and usage are nearly identical. 

The code extends the DeepH framework to spin Hamiltonians with Heisenberg-type exchange 
couplings obtained from [Jx](https://kaist-elst.github.io/Jx.jl/). 
The currently supported DFT package is [OpenMX](http://www.openmx-square.org/).

The Julia versions 1.11.3, 1.12.6, and 1.13.4 have been tested. Newer versions are also expected to work, but have not been tested.
To install Julia, visit https://julialang.org/.

# Usage
## Dataset preparation
To predict exchange couplings in large structures, prepare a training dataset of smaller structures that capture representative local chemical environments of the target system. The exchange couplings are generated by density functional theory (DFT) calculations combined with the magnetic force theorem (MFT). Currently, the combination of OpenMX and Jx is supported.

### After OpenMX & Jx calculation
Once the OpenMX and Jx calculations are complete, you can find ``openmx.out`` and ``jx2.col.spin_0.0/``. The names depend on the calculation settings.

To generate a configuration file for combining the exchange couplings, run:
```
jxbinder config --element {ELEMENT-SEPARATED-BY-COMMA} [--cutoff {}] \
               [--file {openmx.out}] [--jxprefix {jx2.col.spin_0.0/}]
```
This command reads openmx.out in the current directory, and generates an input configuration for the next step. The default values of ``--file`` and ``--jxprefix`` are ``openmx.out`` and ``jx2.col.spin_0.0/``, respectively. ``--cutoff`` is used to set the cutoff length of exchange coupling table file.   
For example, ``jxbinder config --element Mn --cutoff 15.0``. This generates ``sym_param.toml``.

Next, this command will make a combined spin Hamiltonian file ``Spin_Matrix.csv``.
```
jxbinder
```
``Spin_Matrix.csv`` has the Heisenberg exchange couplings sorted by distance. The sign convention is determined by 
$E=-Je_i\cdot e_j$,
where $J > 0$ favors parallel (ferromagnetic) alignment and $J < 0$ favors antiparallel (antiferromagnetic) alignment. Exchange couplings are given in meV.

## Preprocessing
As implemented in DeepH-pack, the ``preprocess`` step converts the data into text and HDF5 formats. 

This process requires ``openmx.out`` and ``Spin_Matrix.csv`` in each folder. The openmx.scfout file is not required at this stage, and there is no need to append the contents of openmx.out to it.

In the configuration file ``preprocess.ini``, set the interface as follows:
``
interface = jx
``
.

With the configuration file prepared, run
```
deeph-preprocess --config preprocess.ini
```

## Training
Training follows the same procedure as in DeepH-pack:
```
deeph-train --config train.ini
```
### Training cutoff radius and loss weight
Two radius parameters control the training loss. 
Note that ``radius`` specifies the cutoff distance for graph contruction during preprocessing. ``radius`` key isn't used for training.  

RenormHNet supports a training cutoff radius (``train_cutoff``) and a loss-weighting radius (``weight_radius``). 

Exchange couplings at distances greater than the cutoff radius $R_\textrm{cutoff}$ do not contribute to the loss function. 
The training cutoff radius should satisfy $R_\textrm{cutoff} < R_\textrm{graph}$. 

The loss-weighting radius $R_\textrm{weight}$ controls the distance-dependent loss weighting. For distances greater than the weight radius, loss contributions are multiplied by ``weight_outer``. 

Set the following parameters in the [train] section:
```
[train]
train_cutoff = 5
weight_radius = 4
weight_outer = 0.7
```

To use the weighted loss function, set the following in the `[hyperparameter]` section:
```
criterion = LengthWeightMaskMSELoss
```
Otherwise, use the default setting, ``criterion = MaskMSELoss``


### Tracking the training log

The training log is written in ``result.txt``. To track the history visually, you can also use TensorBoard by running:
```
tensorboard --logdir=./tensorboard
```

## Inference
Using a trained model, ``inference`` predicts the exchange couplings. 
In the ``inference.ini`` file, you can specify the inference settings. 

Set ``interface = jx``. For example, 
```
[basic]
OLP_dir = {Overlap-only-openmx}
work_dir = {Working-directory-will-be-written}
task = [1,2,3,4,5]
trained_model_dir = {The-directory-has-the-trained-model}
restore_blocks_py = False
interface = jx
```

Tasks 1–4 correspond to the same steps as in DeepH-pack. Task ``1`` parses the overlap matrix, ``2`` constructs local coordinates, ``3`` predicts the Hamiltonian, and Task ``4`` rotates the Hamiltonian back to the global coordinate system.  

Task ``4`` also exports the results from the HDF5 file to ``Hamiltonian.csv``. 
Task ``5`` plots the exchange couplings a function of distance and saves the figure as ``jx_plot.png``.
